# CLYX STUDIO — Website Image Assets

Brand palette: **#8D2168** (magenta) and **#1E2126** (charcoal).

The 13 PNG images in this package were generated as coordinated cinematic visuals for the CLYX STUDIO website. Their CLYX logo treatments are photo-realistic artistic renderings based on the supplied logo reference. For perfectly exact logo outlines, navigation marks, Intro animation, and hero animations, use **logo-original.svg**, not the pixels embedded in the generated photographs.

## Locations in this repository

- Images: `public/images/clyx/<file>.png`, served as `/images/clyx/<file>.png`.
- Each PNG has `<file>-960.webp` and `<file>-1672.webp` beside it, generated by `python scripts/images.py`. The site serves WebP through `picture` and keeps the PNG as the fallback.
- Logo: `public/brand/logo-original.svg` is the only geometry source. `npm run logo:extract` regenerates `src/brand/logo.ts`, `public/brand/clyx-mark.svg`, and `public/brand/clyx-mark-mono.svg` from it; `npm run logo:check` (part of `npm run build`) fails if they drift.
- Image wiring: `src/content/media.ts`.

## Website integration

- Keep HTML headlines, menus, CTAs, overlays, and section labels outside the raster images.
- On mobile use `clyx-mobile-hero.png` instead of heavily cropping the desktop hero.
- Use the official `logo-original.svg` to animate the individual vector components in the Intro and Hero; the background artwork itself is static.
- Prefer responsive `picture`/`srcset` or framework image optimization; convert to WebP/AVIF at deployment where appropriate.
- These visuals are illustrative brand assets. Do not describe them as documentary photos of real CLYX employees, projects, clients, studios, or live events.
- Add actual verified project media separately to the portfolio when available.
